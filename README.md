# Little Kingdom

A minimal browser-based kingdom-building strategy game built with HTML, CSS, and JavaScript.

## Play
Deploy this repository as a static site on Vercel, or open `index.html` in a browser.

## Features
- Gold, food, wood, and stone resources
- Gather resources with working buttons
- Build farms, barracks, and lumber camps
- Advance days to collect building production
- Browser-local save using `localStorage`
- Recent events log and restart option
- Responsive layout for mobile and desktop

## Current limits
This is an early single-player prototype. Progress is stored only in the current browser and does not sync across devices. No backend or database is required yet.
